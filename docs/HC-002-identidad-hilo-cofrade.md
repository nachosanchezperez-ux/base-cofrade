# HC-002 · Identidad de Hilo Cofrade

**Estado:** IMPLEMENTADA / VIGENTE  
**Ámbito:** identidad de producto, interfaz y comunicación

## Decisión

El producto se denomina **Hilo Cofrade** y debe presentarse como una enciclopedia digital contemporánea, rigurosa, visual y navegable de las cofradías, con una identidad común en la web pública y el Panel.

La identidad no debe depender de ornamentación cofrade genérica ni de estilos particulares por entidad. La personalidad del producto nace de una interfaz clara, una jerarquía fuerte, la lógica visual del hilo/nodo y un sistema común capaz de adaptarse a cada Hermandad o Banda sin perder coherencia.

## Reglas

- Nombre de producto: `Hilo Cofrade`.
- Dominio público: `hilocofrade.es`.
- Web pública y Panel pertenecen al mismo producto y comparten disciplina visual.
- Las personalizaciones por entidad se expresan mediante datos y componentes comunes, no mediante diseños ad hoc por `slug`.
- La tipografía se rige por HC-009.
- La identidad cromática de Bandas se rige por HC-010 y su sistema de logotipos por HC-012.

## Regla de no regresión

Una nueva pantalla o entidad debe integrarse en el sistema visual existente. No crear una segunda identidad, familia de componentes o lenguaje gráfico sin una nueva decisión HC.
