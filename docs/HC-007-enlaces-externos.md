# HC-007 · Enlaces externos

**Estado:** IMPLEMENTADA / VIGENTE  
**Ámbito:** enlaces oficiales, escucha, navegación y documentación

## Decisión

Hilo Cofrade distingue los **enlaces externos de interés** de las **Fuentes documentales**. Una web oficial, red social, perfil de Spotify, vídeo o plataforma externa puede facilitar navegación o escucha sin convertirse automáticamente en evidencia canónica de un dato.

## Reglas

- Webs, redes y canales oficiales pueden mostrarse como enlaces de interés de una entidad.
- Los enlaces externos se almacenan como datos editables; no se hardcodean por ficha.
- Spotify, YouTube y plataformas equivalentes pueden servir para escucha o descubrimiento, pero no sustituyen una Fuente documental de autoría, dedicatoria, datación o relación salvo que el contenido concreto aporte esa evidencia y se registre como tal.
- Una Fuente documental se administra mediante `sources` / `source_links` y conserva su alcance.
- Los enlaces a entidades internas de Hilo Cofrade usan rutas canónicas y no se degradan a URLs externas.

## Contratos relacionados

- HC-004 · autoridad de datos estructurados.
- HC-006 · acompañamientos musicales documentados.
- HC-013 · separación entre patrimonio musical, acompañamiento, grabación y plataformas de escucha.

## Regla de no regresión

No utilizar un enlace de reproducción o una URL social como sustituto silencioso de una Fuente cuando el sistema necesita acreditar un dato estructurado.
